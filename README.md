Привет, это небольшой бот для автокликов на вакансии HH RU. Для начала нужно знать:
1. Бот иногда тупит. Помни, он не идеален. 
2. Бот не может отвечать на анкеты, поэтому если по всем параметрам вакансия проходит, то она падает в список "Неудачных кликов", как будет время зайди в этот список и заполни анкеты, как заполнил(а), можешь перести вакансию в список успешных.
3. Бот пока что не может писать сопроводжительное письмо, держи открытым блокнот, со своим письмом, и если пявится это окно, то отправляй, а дальше бот продолжит работу.
4. Бот иногда тупит. Перезагрузи страницу и еще раз вставь код в консоль. Кстит чтобы каждый раз не писать в консоль, нажимай на стрелочку вверх. 

Теперь что делаем:
1. Копируем код из файла https://github.com/avgustinavgustin/hhbot/blob/main/sc-min.js
2. Заходим на страницу поиска, обязательно! Например https://cheboksary.hh.ru/search/vacancy?text=тестировщик&L_save_area=true
3. Открываем консоль браузера(f12 или правой кнопкой мыши => "Просмотреть код" => выбираем "Console"(Консоль). Вставляем код и жмем enter. Все, в будущем можно код больше не копировать, а сразу заходить в консоль и жать стрелочку вверх(у вас вставится последний ваш код из консоли) и так же enter жмем.
4. Ставим свои настройки по необходимости и запускайте.
